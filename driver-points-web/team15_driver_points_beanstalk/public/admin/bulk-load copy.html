Upload a pipe-delimited text file to create organizations, sponsor users, drivers, and optional driver point awards across the platform.

Rules summary

  • Use O, D, and S records.
  • Organization records can be created with O lines, and D/S lines must reference an existing organization.
  • Sponsor records cannot receive points. If points are present, the line is flagged and those fields are ignored.
  • Driver records can create a new driver, move a driver into the target organization, or add points.
  • If points are present, a reason is required.
